# maarif-cikti-cozumleme — hazır istemler

> Bu dosya `docs/istemler.yaml` dosyasından üretilir; elle düzenlenmez.

Köşeli parantezleri doldurup kopyala. Skill yüklü değilse istemin başına şunu ekle: "Maarif Modeli'ne uygun çalış; çıktıları TYMM sayfasından doğrula."

## Temanın çıktı kartı

Programdaki çıktıları, bileşenleri ve sınırları tek kartta görmek için.

```
[sınıf]. sınıf [ders] dersinin [tema adı] temasındaki öğrenme çıktılarını TYMM sayfasından çıkar; her bileşeni beceri basamağıyla eşle, yazılıda ölçülüp ölçülmediğini ve içerik çerçevesi sınırlarını yaz.
```

## Kitap ile program eşlemesi

Ders kitabındaki sayfaların hangi çıktıya denk geldiğini bulmak için.

```
Ekteki ders kitabının [sayfa aralığı] sayfaları programda hangi çıktı ve bileşenlere denk geliyor? Kitapla site arasında fark varsa belirt.
```
