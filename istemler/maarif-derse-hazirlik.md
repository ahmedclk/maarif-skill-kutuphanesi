# maarif-derse-hazirlik — hazır istemler

**Ne işe yarar:** Bir derse birlikte hazırlanmak.

Köşeli parantezleri doldurup kopyala. Skill yüklü değilse istemin başına şunu ekle: "Maarif Modeli'ne uygun çalış; çıktıları TYMM sayfasından doğrula."

## 1

```
Ekteki ders planıyla yarınki derse hazırlanmama yardım et. Kilit görevi önce ben çözeyim.
```

## 2

```
Kitabın [sayfa] sayfasındaki etkinliği anlatmadan önce öğrencilerin nerede takılacağını birlikte düşünelim.
```
